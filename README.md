# 📩 SMKS MAESTRO - Sistem Nomor Surat Otomatis

## 🎯 Tentang Aplikasi
Aplikasi ini digunakan untuk memudahkan guru SMKS MAESTRO dalam mengajukan nomor surat keluar secara otomatis. Admin akan menyetujui permintaan sebelum nomor surat diberikan.

## 👤 Login Admin
- **Username:** `admin`
- **Password:** `admin123`

*Silakan ganti setelah login pertama di menu Pengaturan*

## 📋 Fitur
1. **Guru:**
   - Mengajukan permintaan nomor surat keluar
   - Memilih nama dari dropdown
   - Preview format nomor surat
   - Melihat status permintaan

2. **Admin:**
   - Menyetujui/menolak permintaan
   - Kelola data guru (tambah/hapus)
   - Atur nomor urut manual
   - Reset nomor urut
   - Hapus data tahun lalu
   - Ganti username & password
   - Export data ke Excel (CSV)
   - Log aktivitas
